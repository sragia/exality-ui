# ExalityUI

Basically addon I built for myself. As such many choices that are made are not let's say user friendly.

Goal for the addon is to be able to control as much as possible from what Blizzard allows us to. That said some choices I have made are specifically targetting me, basically saying this UI addon is not for everyone and probably never will cater for everyone

Still very much in not stable state, nor likely ever will be. It's as usable as it is for me to play the game.

Also I ain't gonna lie, have been using AI for this a bit. Core of it isn't AI but some newer features are. So if that's a turn off for you, I get that. I do test stuff here so it's not like I am going in totally blind, and have like 10y of experience of making addons so not like I am doing this blindly. To other addon authors, I have looked through the code and I don't think there's anything that has been stolen, but if you see something, feel free to contact me on Discord or make Issue on github and I will remove it.
