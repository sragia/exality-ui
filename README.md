Basically addon I built for myself. As such many choices that are made are not let's say user friendly.

Goal for the addon is to be able to control as much as possible from what Blizzard allows us to. That said some choices I have made are specifically targetting me, basically saying this UI addon is not for everyone and probably never will cater for everyone

Still very much in not stable state, nor likely ever will be. It's as usable as it is for me to play the game.

Also I ain't gonna lie, have been using AI for this a bit. Core of it isn't AI but some newer features are. So if that's a turn off for you, I get that. I do test stuff here so it's not like I am going in totally blind. To other addon authors, I have looked through the code and I don't think there's anything that has been stolen, but if you see something, feel free to contact me on Discord or make Issue on github and I will remove it.

# Features

- **Unit Frames**
  - Single unit and group (party/raid) unit included
- **Action Bars**
- **Resource Displays**
  - Simple resource displays for Energy, Rage, Holy Power, DK Runes etc.
- **Aura Displays**
  - Customizable aura displays where you can set any filters that Blizzard allows, and adjust them visually however you want
- **Cooldown Displays**
  - Display spell, item cooldown icons, stacks and adjust them visually
- **Minimap**
  - Simplistic minimap styling with button configuration
- **Data Broker displays**
  - Fairly basic text displays for data broker providers, like showing clock, friends, guild or anything else from other addons
- **Raid Tools**
  - Ready Check and Pull Timer buttons, Encounter Time and Battle Res displays
- **XP Bar**
  - Inspired from Luxthos old WA to show you your current XP bar and some statistics of how fast you are leveling
- **Custom Objective Tracker**
- **Basic M+ Timer display**
- **Notifications** that show couple different QoL things like low bag space/repair needed/ what loot you received
- **Custom Character Frame**
- **Skinning**
  - Skinned blizzard frames
